ସୁଜିତ୍ କ୍ଲାସେସ୍
ମାନସିକ ମାନଚିତ୍ର ମୁଖ୍ୟ ଧାରଣା କାର୍ଯ୍ୟକଳାପ ସମାଧାନ NCERT ପ୍ରଶ୍ନୋତ୍ତର ଇଣ୍ଟରାକ୍ଟିଭ୍ କୁଇଜ୍ ପରୀକ୍ଷା ଟିପ୍ସ
NEP ୨୦୨୦ ପାଠ୍ୟକ୍ରମ • ସପ୍ତମ ଶ୍ରେଣୀ ଗଣିତ (ଗଣିତ ପ୍ରକାଶ)

ଅଧ୍ୟାୟ ୪: ଅକ୍ଷର-ସଂଖ୍ୟା ବ୍ୟବହାର କରି ରାଶିମାଳା
(Expressions using Letter-Numbers)

ବ୍ୟାପକ ସଂଖ୍ୟା ଭାବେ ଚଳରାଶି (Variables), ଦିଆସିଲି କାଠି ପାଟର୍ଣ୍ଣ, ପଦ ଓ ସହଗ, ସଦୃଶ ଓ ବିସଦୃଶ ପଦ ଏବଂ ରାଶିମାଳାର ସରଳୀକରଣ।

ମୂଳ ପୃଷ୍ଠା » ସପ୍ତମ ଶ୍ରେଣୀ ଗଣିତ » ଅଧ୍ୟାୟ ୪: ଅକ୍ଷର-ସଂଖ୍ୟା ବ୍ୟବହାର କରି ରାଶିମାଳା
Section 1

ଅଧ୍ୟାୟର ରୂପରେଖ ଓ ମାନସିକ ମାନଚିତ୍ର (Visual Mind Map)

ସଂଖ୍ୟା ସ୍ଥାନରେ ଅକ୍ଷର ବ୍ୟବହାର କରି କିପରି ସାର୍ବଜନୀନ ଗାଣିତିକ ନିୟମ ଗଠନ ହୁଏ ତାହା ବୁଝନ୍ତୁ।

ଶିକ୍ଷକଙ୍କ ପ୍ରବେଶ ବାର୍ତ୍ତା: ଆପଣ କେବେ ଭାବିଛନ୍ତି କି ଗଣିତରେ x, y, n, କିମ୍ବା a ଭଳି ଅକ୍ଷର କାହିଁକି ଆସେ? ପାଟିଗଣିତରେ ୫ ର ମାନ ସର୍ବଦା ୫ ରହିଥାଏ। କିନ୍ତୁ ଗୋଟିଏ ଅକ୍ଷର ଯେକୌଣସି ଅଜ୍ଞାତ ବା ପରିବର୍ତ୍ତନଶୀଳ ସଂଖ୍ୟାର ସ୍ଥାନ ନେଇପାରେ! ଯଦି ଶବନମ୍ ଆଫତାବଙ୍କ ଠାରୁ ୩ ବର୍ଷ ବଡ଼, ତେବେ ଆଫତାବଙ୍କ ବୟସ a ବର୍ଷ ହେଲେ ଶବନମଙ୍କ ବୟସ ସର୍ବଦା a + 3 ବର୍ଷ ହେବ। ଏହି ଶକ୍ତିଶାଳୀ ଧାରଣାକୁ ବୀଜଗଣିତ (Algebra) କୁହାଯାଏ!

ଚିତ୍ର ୪.୧: ଅକ୍ଷର-ସଂଖ୍ୟା ରାଶିମାଳାର ସାଂରଚନିକ ସଂକଳ୍ପ ମାନଚିତ୍ର

Section 2

ଗଭୀର ଧାରଣା ଓ ଶିକ୍ଷକଙ୍କ ସରଳ ବିଶ୍ଳେଷଣ (Core Concepts)

ଚଳରାଶି, ଗୁଣନ ଚିହ୍ନ ବର୍ଜନ, ସଦୃଶ ପଦ ଓ ବୀଜଗାଣିତିକ ସରଳୀକରଣ।

୪.୧ ଚଳରାଶି କ'ଣ? (What is a Variable?)

ଯେଉଁ ଅକ୍ଷର ଗୁଡ଼ିକ ଏକ ଅଜ୍ଞାତ ବା ପରିବର୍ତ୍ତନଶୀଳ ସଂଖ୍ୟାକୁ ସୂଚାନ୍ତି, ସେଗୁଡ଼ିକୁ ଚଳରାଶି (Variables) କୁହାଯାଏ। ଉଦାହରଣ ସ୍ୱରୂପ:

  • ଆଫତାବଙ୍କ ବୟସ = a ବର୍ଷ।
  • ଶବନମ୍ ତାଙ୍କ ଠାରୁ ୩ ବର୍ଷ ବଡ଼ ⇒ ଶବନମଙ୍କ ବୟସ = a + ୩ ବର୍ଷ।
  • ଯଦି ଆଫତାବ ୧୦ ବର୍ଷର ହୁଅନ୍ତି ⇒ ଶବନମ୍ = ୧୦ + ୩ = ୧୩ ବର୍ଷ।
  • ଯଦି ଆଫତାବ ୨୫ ବର୍ଷର ହୁଅନ୍ତି ⇒ ଶବନମ୍ = ୨୫ + ୩ = ୨୮ ବର୍ଷ। a + ୩ ନିୟମଟି ସର୍ବଦା ସତ୍ୟ!

ଚିତ୍ର ୪.୨: ସଂଲଗ୍ନ ଦିଆସିଲି କାଠି ବର୍ଗର ପାଟର୍ଣ୍ଣ। w ଟି ବର୍ଗ ପାଇଁ ଆବଶ୍ୟକ କାଠି ସଂଖ୍ୟା = ୩w + ୧।

୪.୨ ଗୁଣନ ଚିହ୍ନ ବର୍ଜନ ନିୟମ (Omitting Multiplication Sign)

ବୀଜଗଣିତରେ ୪ × x କୁ କେବଳ ୪x ଏବଂ a × b କୁ ab ଲେଖାଯାଏ। ଏହାର କାରଣ ହେଲା ଗୁଣନ ଚିହ୍ନ (×) ଏବଂ ଇଂରାଜୀ ଅକ୍ଷର (x) ଦେଖିବାକୁ ପ୍ରାୟ ସମାନ!
• ୧ × x କୁ ସାଧାରଣତଃ x ଲେଖାଯାଏ (୧x ନୁହେଁ)।
• −୧ × y କୁ −y ଲେଖାଯାଏ।

୪.୩ ସଦୃଶ ପଦ ବନାମ ବିସଦୃଶ ପଦ (Like vs. Unlike Terms)

ବୀଜଗଣିତର ଫଳ ଟୋକେଇ ନିୟମ:
• ସଦୃଶ ପଦ (Like Terms): ଯେଉଁ ପଦଗୁଡ଼ିକର ଚଳରାଶି ଏବଂ ସେମାନଙ୍କର ଘାତ ସମ୍ପୂର୍ଣ୍ଣ ସମାନ ଥାଏ। (ଯଥା: ୩ଟି ସେଓ + ୫ଟି ସେଓ = ୮ଟି ସେଓ ⇒ ୩x + ୫x = ୮x)। ସଦୃଶ ପଦଗୁଡ଼ିକ ଯୋଗ ଓ ବିୟୋଗ ହୋଇପାରନ୍ତି।
• ବିସଦୃଶ ପଦ (Unlike Terms): ଯେଉଁ ପଦଗୁଡ଼ିକର ଚଳରାଶି ଭିନ୍ନ ଥାଏ। (ଯଥା: ୩ଟି ସେଓ + ୪ଟି କଦଳୀ କଦାପି ୭ଟି ସେଓ-କଦଳୀ ହୋଇପାରିବ ନାହିଁ! ⇒ ୩x + ୪y ଅପରିବର୍ତ୍ତିତ ରହିବ)।
Section 3

ପାଠ୍ୟପୁସ୍ତକ ଅନ୍ତର୍ଗତ କାର୍ଯ୍ୟକଳାପର ସମ୍ପୂର୍ଣ୍ଣ ସମାଧାନ (In-Text Activities)

ପରିସୀମା ସୂତ୍ର, ସରଳୀକରଣ ଅଭ୍ୟାସ ଓ ଗଭୀର କୂଅରେ ଶାମୁକାର ସମାଧାନ।

କାର୍ଯ୍ୟକଳାପ ୧: ସମବାହୁ ବହୁଭୁଜର ପରିସୀମା ସୂତ୍ର (ପୃଷ୍ଠା ୪)

(କ) s ବାହୁ ବିଶିଷ୍ଟ ସମବାହୁ ତ୍ରିଭୁଜ: ୩ଟି ବାହୁ ପରସ୍ପର ସମାନ ⇒ ପରିସୀମା = s + s + s = ୩s।
(ଖ) s ବାହୁ ବିଶିଷ୍ଟ ସୁଷମ ପଞ୍ଚଭୁଜ: ୫ଟି ବାହୁ ପରସ୍ପର ସମାନ ⇒ ପରିସୀମା = s + s + s + s + s = ୫s।
(ଗ) s ବାହୁ ବିଶିଷ୍ଟ ସୁଷମ ଷଡ଼ଭୁଜ: ୬ଟି ବାହୁ ପରସ୍ପର ସମାନ ⇒ ପରିସୀମା = ୬ × s = ୬s।

କାର୍ଯ୍ୟକଳାପ ୨: ରାଶିମାଳାର ସରଳୀକରଣ ଅଭ୍ୟାସ (ପୃଷ୍ଠା ୧୪)

(କ) p + p + p + p = ୪p
(ଖ) p + q + p − q = (p + p) + (q − q) = ୨p
(ଗ) p − q + p − q = (p + p) − (q + q) = ୨p − ୨q
(ଘ) p + q − p + q = (p − p) + (q + q) = ୨q
(ଙ) p + q − (p + q) = p + q − p − q = ୦
(ଚ) ୨d − d − (d − c) = ୨d − d − d + c = c

କାର୍ଯ୍ୟକଳାପ ୩: ଗଭୀର କୂଅରେ ଶାମୁକା (The Snail in the Deep Well - ପୃଷ୍ଠା ୩୫)

ପ୍ରଶ୍ନ: ଗୋଟିଏ ଶାମୁକା ଦିନବେଳା u ସେମି ଉପରକୁ ଚଢ଼େ ଏବଂ ରାତିରେ d ସେମି ତଳକୁ ଖସିଯାଏ। ଏହି ପ୍ରକ୍ରିୟା ୧୦ ଦିନ ଓ ରାତି ଧରି ଚାଲିଲା।

ଭାଗ (କ): ୧୦ ଦିନ ଓ ରାତି ପରେ ଶାମୁକାଟି ମୋଟ କେତେ ଦୂରତା ଚଢ଼ିବ?
ପ୍ରତି ୨୪ ଘଣ୍ଟାରେ ଅଗ୍ରଗତି = (u − d) ସେମି।
୧୦ ଦିନରେ ନିଟ୍ ଦୂରତା = ୧୦(u − d) ସେମି।
ଭାଗ (ଖ): ଯଦି d > u ହୁଏ, ତେବେ କ’ଣ ଘଟିବ?
ଯଦି ଖସିବା ପରିମାଣ (d) ଚଢ଼ିବା ପରିମାଣ (u) ଠାରୁ ଅଧିକ ହୁଏ, ତେବେ (u − d) ଋଣାତ୍ମକ ହେବ। ଅର୍ଥାତ୍ ଶାମୁକାଟି ଆରମ୍ଭ ବିନ୍ଦୁ ଠାରୁ ଆହୁରି ତଳକୁ ଖସିଯିବ!
✓ ଉତ୍ତର: (କ) ୧୦(u − d) ସେମି; (ଖ) ଶାମୁକାଟି ତଳକୁ ଖସିବ।
Section 4

୧୦୦% ସମ୍ପୂର୍ଣ୍ଣ NCERT ଅଭ୍ୟାସ ପ୍ରଶ୍ନାବଳୀ ସମାଧାନ (Figure it Out)

ପାଠ୍ୟପୁସ୍ତକ ଅନୁଶୀଳନୀର ସମସ୍ତ ଗାଣିତିକ ପ୍ରଶ୍ନର ପୂର୍ଣ୍ଣ ସମାଧାନ।

ପ୍ରଶ୍ନ ୧: ରେସ୍ତୋରାଁରେ ଖାଦ୍ୟ ବିଲ୍ ପ୍ରସ୍ତୁତି (ପୃଷ୍ଠା ୨୨)

ପ୍ରଶ୍ନ: ଗୋଟିଏ ପ୍ଲେଟ୍ ଜୁଆର ରୁଟିର ମୂଲ୍ୟ ₹୩୦ ଏବଂ ଗୋଟିଏ ପ୍ଲେଟ୍ ପଲାଉର ମୂଲ୍ୟ ₹୨୦। ଯଦି ଜଣେ ଗ୍ରାହକ x ପ୍ଲେଟ୍ ଜୁଆର ରୁଟି ଏବଂ y ପ୍ଲେଟ୍ ପଲାଉ ଅର୍ଡର କରନ୍ତି, ତେବେ ମୋଟ ବିଲ୍ ପାଇଁ ଏକ ବୀଜଗାଣିତିକ ରାଶିମାଳା ଲେଖ।

ଜୁଆର ରୁଟିର ମୂଲ୍ୟ: ୩୦ × x = ₹୩୦x
ପଲାଉର ମୂଲ୍ୟ: ୨୦ × y = ₹୨୦y
ମୋଟ ବିଲ୍: ୩୦x + ୨୦y
✓ ମୋଟ ବିଲ୍ ପାଇଁ ରାଶିମାଳା: ₹(୩୦x + ୨୦y)।
ପ୍ରଶ୍ନ ୨: ଦିଆସିଲି କାଠି ବର୍ଗ ନିୟମ (ପୃଷ୍ଠା ୨୪)

ପ୍ରଶ୍ନ: ଧାଡ଼ିରେ ୧୦ଟି ସଂଲଗ୍ନ ବର୍ଗ ତିଆରି କରିବା ପାଇଁ କେତୋଟି ଦିଆସିଲି କାଠି ଆବଶ୍ୟକ? w ଟି ବର୍ଗ ପାଇଁ ସାଧାରଣ ନିୟମ କ'ଣ?

ପାଟର୍ଣ୍ଣ ଅନୁଧ୍ୟାନ:
୧ ଟି ବର୍ଗ = ୪ କାଠି = ୩(୧) + ୧
୨ ଟି ବର୍ଗ = ୭ କାଠି = ୩(୨) + ୧
୩ ଟି ବର୍ଗ = ୧୦ କାଠି = ୩(୩) + ୧
ସାଧାରଣ ସୂତ୍ର: w ଟି ବର୍ଗ ପାଇଁ ଆବଶ୍ୟକ କାଠି = ୩w + ୧।
୧୦ ଟି ବର୍ଗ ପାଇଁ: ୩(୧୦) + ୧ = ୩୦ + ୧ = ୩୧ ଟି କାଠି।
✓ ଉତ୍ତର: ୧୦ ଟି ବର୍ଗ ପାଇଁ ୩୧ ଟି କାଠି; w ଟି ବର୍ଗ ପାଇଁ ୩w + ୧।
ପ୍ରଶ୍ନ ୩: ସରଳ କର: (୪x + ୩y) − (୩x + ୪y) (ପୃଷ୍ଠା ୧୪)
ପଦକ୍ଷେପ ୧ (ବନ୍ଧନୀ ଫିଟାଇବା): ଦ୍ୱିତୀୟ ବନ୍ଧନୀ ପୂର୍ବରୁ ବିୟୋଗ ଚିହ୍ନ ଥିବାରୁ ଭିତରର ପ୍ରତ୍ୟେକ ପଦର ଚିହ୍ନ ବଦଳିବ:
(୪x + ୩y) − (୩x + ୪y) = ୪x + ୩y − ୩x − ୪y।
ପଦକ୍ଷେପ ୨ (ସଦୃଶ ପଦ ଏକତ୍ର କରିବା):
= (୪x − ୩x) + (୩y − ୪y)।
ପଦକ୍ଷେପ ୩ (ସହଗ ସରଳୀକରଣ):
= ୧x − ୧y = x − y।
✓ ସରଳୀକୃତ ମାନ: x − y।

ପରୀକ୍ଷାରେ ଭୁଲରୁ ବଞ୍ଚିବା ପାଇଁ ଶିକ୍ଷକଙ୍କ ପରାମର୍ଶ ଓ ଦ୍ରୁତ ପୁନରାବୃତ୍ତି ସୂତ୍ର।

ପରୀକ୍ଷାରେ ଏହି ସାଧାରଣ ଭୁଲ କେବେ କରିବେ ନାହିଁ:

• ବନ୍ଧନୀ ପୂର୍ବର ବିୟୋଗ ଚିହ୍ନକୁ ଅଣଦେଖା କରିବା: −(୩x + ୪y) ଫିଟାଇଲେ −୩x − ୪y ହୁଏ। କେବଳ −୩x + ୪y ଲେଖିଲେ ଭୁଲ ହେବ।
