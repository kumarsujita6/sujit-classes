ସୁଜିତ୍ କ୍ଲାସେସ୍
ମାନସିକ ମାନଚିତ୍ର ମୁଖ୍ୟ ଧାରଣା କାର୍ଯ୍ୟକଳାପ ସମାଧାନ NCERT ପ୍ରଶ୍ନୋତ୍ତର ଇଣ୍ଟରାକ୍ଟିଭ୍ କୁଇଜ୍ ପରୀକ୍ଷା ଟିପ୍ସ
NEP ୨୦୨୦ ପାଠ୍ୟକ୍ରମ • ସପ୍ତମ ଶ୍ରେଣୀ ଗଣିତ (ଗଣିତ ପ୍ରକାଶ)

ଅଧ୍ୟାୟ ୫: ସମାନ୍ତର ଓ ଛେଦୀ ସରଳରେଖା
(Parallel and Intersecting Lines)

ପ୍ରତୀପ କୋଣ, ରୈଖିକ ଯୁଗ୍ମ, ଛେଦକ ଦ୍ୱାରା ସୃଷ୍ଟ ଅନୁରୂପ କୋଣ (F-ଆକୃତି), ଏକାନ୍ତର କୋଣ (Z-ଆକୃତି) ଏବଂ ସମାନ୍ତରତା ପରୀକ୍ଷାର ପୂର୍ଣ୍ଣାଙ୍ଗ ମାଷ୍ଟର ନୋଟ୍ସ।

ମୂଳ ପୃଷ୍ଠା » ସପ୍ତମ ଶ୍ରେଣୀ ଗଣିତ » ଅଧ୍ୟାୟ ୫: ସମାନ୍ତର ଓ ଛେଦୀ ସରଳରେଖା
Section 1

ଅଧ୍ୟାୟର ରୂପରେଖ ଓ ମାନସିକ ମାନଚିତ୍ର (Visual Mind Map)

ସରଳରେଖା, ଛେଦକ ଏବଂ କୋଣମାନଙ୍କ ମଧ୍ୟରେ ଥିବା ଜ୍ୟାମିତିକ ସମ୍ପର୍କକୁ ଗୋଟିଏ ନଜରରେ ବୁଝନ୍ତୁ।

ଶିକ୍ଷକଙ୍କ ପ୍ରବେଶ ବାର୍ତ୍ତା: ରେଳ ଧାରଣା କିମ୍ବା ଝରକାର ଗ୍ରିଲ୍ କୁ ଲକ୍ଷ୍ୟ କରନ୍ତୁ: ଦୁଇଟି ସିଧା ରେଖା ପାଖାପାଖି ଯାଉଛନ୍ତି, କିନ୍ତୁ କେବେ ପରସ୍ପରକୁ ଛୁଉଁ ନାହାନ୍ତି ଏବଂ ସେମାନଙ୍କ ମଧ୍ୟରେ ଦୂରତା ସର୍ବଦା ସମାନ ରହୁଛି। ଏଗୁଡ଼ିକ ହେଉଛନ୍ତି ସମାନ୍ତର ସରଳରେଖା (Parallel Lines)! ଯେତେବେଳେ ତୃତୀୟ ଗୋଟିଏ ରେଖା (ଛେଦକ - Transversal) ସେମାନଙ୍କୁ ଛେଦ କରେ, ସେତେବେଳେ ୮ଟି କୋଣ ସୃଷ୍ଟି ହୁଏ। କେବଳ ଗୋଟିଏ କୋଣର ମାପ ଜାଣିଲେ ଆମେ ବାକି ୭ଟି ଯାକ କୋଣର ମାପ ସହଜରେ କହିପାରିବା! ଆସନ୍ତୁ ଜାଣିବା ଏହି ଚମତ୍କାର ଜ୍ୟାମିତିକ ନିୟମଗୁଡ଼ିକ।

ଚିତ୍ର ୫.୧: ସମାନ୍ତର ଓ ଛେଦୀ ସରଳରେଖା ସମ୍ବନ୍ଧୀୟ ସମ୍ପୂର୍ଣ୍ଣ ମାନସିକ ମାନଚିତ୍ର

Section 2

ଗଭୀର ଧାରଣା ଓ ଶିକ୍ଷକଙ୍କ ସରଳ ବିଶ୍ଳେଷଣ (Core Concepts)

କୋଣର ପ୍ରକାରଭେଦ, ପ୍ରମାଣ, ଛେଦକ ଜ୍ୟାମିତି ଏବଂ F, Z, C ନିୟମ।

୫.୧ ଛେଦୀ ସରଳରେଖା ଓ ପ୍ରତୀପ କୋଣ (Vertically Opposite Angles)

ଯେତେବେଳେ ଦୁଇଟି ସରଳରେଖା ପରସ୍ପରକୁ ଛେଦ କରନ୍ତି, ଛେଦ ବିନ୍ଦୁରେ ଚାରୋଟି କୋଣ ସୃଷ୍ଟି ହୁଏ। ପରସ୍ପର ବିପରୀତ ଦିଗରେ ଥିବା କୋଣ ଯୋଡ଼ିକୁ ପ୍ରତୀପ କୋଣ (Vertically Opposite Angles) କୁହାଯାଏ।

ପ୍ରତୀପ କୋଣ ସମାନତାର ପ୍ରମାଣ (Proof):
ଧରାଯାଉ ଦୁଇଟି ରେଖା ପରସ୍ପରକୁ O ବିନ୍ଦୁରେ ଛେଦ କରି କ୍ରମାନ୍ୱୟରେ a, b, c, d ଚାରୋଟି କୋଣ ସୃଷ୍ଟି କରିଛନ୍ତି।
• ଏକ ସରଳରେଖା ଉପରିସ୍ଥ ରୈଖିକ ଯୁଗ୍ମ କୋଣମାନଙ୍କର ଯୋଗଫଳ ୧୮୦°: a + b = ୧୮୦° (ସମୀକରଣ ୧)।
• ଅନୁରୂପ ଭାବେ ଅନ୍ୟ ପାଖରେ: b + c = ୧୮୦° (ସମୀକରଣ ୨)।
• ସମୀକରଣ ୧ ରୁ ସମୀକରଣ ୨ ବିୟୋଗ କଲେ: (a + b) − (b + c) = ୧୮୦° − ୧୮୦° ⇒ a − c = ୦ ⇒ a = c!
ତେଣୁ, ପ୍ରତୀପ କୋଣ ସର୍ବଦା ପରସ୍ପର ସମାନ।

ଚିତ୍ର ୫.୨: ଦୁଇଟି ସମାନ୍ତର ରେଖା l ଓ m କୁ ଏକ ଛେଦକ t ଛେଦ କଲେ ସୃଷ୍ଟି ହେଉଥିବା ୮ଟି କୋଣ

୫.୨ ଛେଦକ ଦ୍ୱାରା ସୃଷ୍ଟ କୋଣମାନଙ୍କର ସମ୍ପର୍କ (F, Z, C ନିୟମ)

କୋଣର ପ୍ରକାର ଇଂରାଜୀ ଅକ୍ଷର ଆକୃତି କୋଣ ଯୁଗ୍ମ (ଚିତ୍ର ୫.୨ ଅନୁସାରେ) ଗାଣିତିକ ଧର୍ମ
ଅନୁରୂପ କୋଣ (Corresponding Angles) F-ଆକୃତି ∠୧ ଓ ∠୫, ∠୨ ଓ ∠୬, ∠୩ ଓ ∠୭, ∠୪ ଓ ∠୮ ସମାନ (∠୧ = ∠୫, ∠୨ = ∠୬...)
ଏକାନ୍ତର ଅନ୍ତଃସ୍ଥ କୋଣ (Alternate Interior) Z-ଆକୃତି ∠୩ ଓ ∠୬, ∠୪ ଓ ∠୫ ସମାନ (∠୩ = ∠୬, ∠୪ = ∠୫)
ଏକାନ୍ତର ବହିଃସ୍ଥ କୋଣ (Alternate Exterior) ବାହ୍ୟ Z ∠୧ ଓ ∠୮, ∠୨ ଓ ∠୭ ସମାନ (∠୧ = ∠୮, ∠୨ = ∠୭)
ଛେଦକର ଏକପାର୍ଶ୍ୱସ୍ଥ ଅନ୍ତଃକୋଣ (Co-Interior Angles) C-ଆକୃତି / U-ଆକୃତି ∠୩ ଓ ∠୫, ∠୪ ଓ ∠୬ ପରିପୂରକ (ଯୋଗଫଳ = ୧୮୦°)
Section 3

ପାଠ୍ୟପୁସ୍ତକ ଅନ୍ତର୍ଗତ କାର୍ଯ୍ୟକଳାପର ସମ୍ପୂର୍ଣ୍ଣ ସମାଧାନ (In-Text Activities)

ଅଜ୍ଞାତ କୋଣ ଅନ୍ୱେଷଣ ଓ ସମାନ୍ତରତା ପରୀକ୍ଷାର ପଦକ୍ଷେପ-ୱାରୀ ସମାଧାନ।

କାର୍ଯ୍ୟକଳାପ ୧: କୋଣ ଅନ୍ୱେଷଣ ଅଭ୍ୟାସ (ପୃଷ୍ଠା ୧୮)

(କ) ୪୮° ସହିତ ପ୍ରତୀପ ଭାବେ ଥିବା କୋଣ: ପ୍ରତୀପ କୋଣ ପରସ୍ପର ସମାନ ⇒ a = ୪୮°।
(ଖ) ସରଳରେଖାରେ ୫୨° ର ସଂଲଗ୍ନ କୋଣ: ରୈଖିକ ଯୁଗ୍ମ ହେତୁ ⇒ b = ୧୮୦° − ୫୨° = ୧୨୮°।
(ଗ) ୮୧° ଓ ୯୯° ଛେଦକ କୋଣ: ଛେଦକର ଏକପାର୍ଶ୍ୱସ୍ଥ ଅନ୍ତଃକୋଣ ଯୋଗଫଳ = ୮୧° + ୯୯° = ୧୮୦° (ସମାନ୍ତର ରେଖା ପ୍ରମାଣିତ)। ପ୍ରତୀପ କୋଣ ନିୟମ ଅନୁସାରେ c = ୮୧°, d = ୯୯°।

କାର୍ଯ୍ୟକଳାପ ୨: a, b, c ରେଖାମାନଙ୍କର ସମାନ୍ତରତା ପରୀକ୍ଷା (ପୃଷ୍ଠା ୯)

ପ୍ରଶ୍ନ: ରେଖା a ଏବଂ ଛେଦକ ମଧ୍ୟରେ କୋଣ ୭୫°। ରେଖା b ର ଅନୁରୂପ କୋଣ ୭୫°। ରେଖା c ର ଅନୁରୂପ କୋଣ ୭୨°। କେଉଁ ରେଖାଟି a ସହିତ ସମାନ୍ତର?

ଶର୍ତ୍ତ: ଯଦି ଦୁଇଟି ରେଖା ପାଇଁ ଛେଦକର ଅନୁରୂପ କୋଣଦ୍ୱୟ ସମାନ ହୁଅନ୍ତି, ତେବେ ରେଖାଦ୍ୱୟ ପରସ୍ପର ସମାନ୍ତର ହେବେ।
ରେଖା a ଓ b ପାଇଁ: ଉଭୟଙ୍କ ଅନୁରୂପ କୋଣ ୭୫° (ସମାନ)। ତେଣୁ ରେଖା b || ରେଖା a।
ରେଖା a ଓ c ପାଇଁ: ଅନୁରୂପ କୋଣ ୭୫° ଏବଂ ୭୨° (ଅସମାନ: ୭୫° ≠ ୭୨°)। ତେଣୁ ରେଖା c ସମାନ୍ତର ନୁହେଁ।
✓ ଉତ୍ତର: ରେଖା b ରେଖା a ସହିତ ସମାନ୍ତର।
Section 4

୧୦୦% ସମ୍ପୂର୍ଣ୍ଣ NCERT ଅଭ୍ୟାସ ପ୍ରଶ୍ନାବଳୀ ସମାଧାନ (Figure it Out)

ପାଠ୍ୟପୁସ୍ତକ ଅନୁଶୀଳନୀର ସମସ୍ତ ଗାଣିତିକ ପ୍ରଶ୍ନର ପୂର୍ଣ୍ଣ ସମାଧାନ।

ପ୍ରଶ୍ନ ୧: ସମାନ୍ତର ରେଖା ଓ ଲମ୍ବ ପ୍ରଶ୍ନ (ପୃଷ୍ଠା ୨୦, ଚିତ୍ର ୫.୩୪)

ପ୍ରଶ୍ନ: ଚିତ୍ର ୫.୩୪ ରେ AB || CD ଏବଂ CD || EF। ଆହୁରି ମଧ୍ୟ EA ⊥ AB। ଯଦି ∠BEF = ୫୫°, ତେବେ x ଏବଂ y ର ମାନ ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ପଦକ୍ଷେପ ୧: ଯେହେତୁ CD || EF ଏବଂ BE ହେଉଛି ଏକ ଛେଦକ।
x ଏବଂ ∠BEF ହେଉଛନ୍ତି ଛେଦକର ଏକପାର୍ଶ୍ୱସ୍ଥ ଅନ୍ତଃକୋଣ (Co-interior angles)।
ତେଣୁ, x + ୫୫° = ୧୮୦° ⇒ x = ୧୮୦° − ୫୫° = ୧୨୫°।
ପଦକ୍ଷେପ ୨: ଯେହେତୁ AB || CD ଏବଂ ସମାନ ଛେଦକ ସେମାନଙ୍କୁ ଛେଦ କରୁଛି।
x ଏବଂ y ହେଉଛନ୍ତି ଅନୁରୂପ କୋଣ (F-ଆକୃତି)।
ତେଣୁ, y = x = ୧୨୫°।
✓ ଉତ୍ତର: x = ୧୨୫° ଏବଂ y = ୧୨୫°।
ପ୍ରଶ୍ନ ୨: ବକ୍ର କୋଣ ପଥ: ∠NOP ନିର୍ଣ୍ଣୟ (ପୃଷ୍ଠା ୨୦, ଚିତ୍ର ୫.୩୫)

ପ୍ରଶ୍ନ: ଚିତ୍ର ୫.୩୫ ରେ ରେଖା LM || PQ। ∠LNO = ୪୦°, ∠N = ୯୬°, ଏବଂ ∠OPQ = ୫୨°। ∠NOP ର ମାନ ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।

ଅଙ୍କନ: N ବିନ୍ଦୁ ଏବଂ O ବିନ୍ଦୁ ଦେଇ LM ସହିତ ସମାନ୍ତର ସରଳରେଖା ଅଙ୍କନ କରନ୍ତୁ।
N ବିନ୍ଦୁରେ କୋଣ ବିଭାଜନ: ୪୦° ର ଏକାନ୍ତର କୋଣ ୪୦° ହେବ। ମୋଟ ∠N = ୯୬° ହୋଇଥିବାରୁ, ଅବଶିଷ୍ଟ ତଳ କୋଣ = ୯୬° − ୪୦° = ୫୬°।
O ବିନ୍ଦୁରେ କୋଣ ଗଠନ:
• ∠NOP ର ଉପର ଭାଗ ୫୬° ସହିତ ଏକାନ୍ତର କୋଣ ⇒ ୫୬°।
• ∠NOP ର ତଳ ଭାଗ ∠OPQ (୫୨°) ସହିତ ଏକାନ୍ତର କୋଣ ⇒ ୫୨°।
ସମୁଦାୟ କୋଣ: ∠NOP = ୫୬° + ୫୨° = ୧୦୮°।
✓ ଉତ୍ତର: ∠NOP = ୧୦୮°।
Section 5

ଇଣ୍ଟରାକ୍ଟିଭ୍ ପରୀକ୍ଷା ପ୍ରଶ୍ନୋତ୍ତର ବ୍ୟାଙ୍କ ଓ କୁଇଜ୍ (Interactive Quiz Engine)

ସଠିକ୍ ଉତ୍ତର ବାଛି ତୁରନ୍ତ ଫଳାଫଳ ପାଆନ୍ତୁ!

🎯 ଆପଣଙ୍କ ସ୍କୋର: ୦ / ୫ ସଠିକ୍ ସମସ୍ତ ପ୍ରଶ୍ନର ଉତ୍ତର ଦିଅନ୍ତୁ!
ପ୍ରଶ୍ନ ୧: ଦୁଇଟି ସରଳରେଖାର ଛେଦ ବିନ୍ଦୁରେ ଗୋଟିଏ କୋଣ ୭୦° ହେଲେ ତାର ପ୍ରତୀପ କୋଣ (Vertically Opposite Angle) କେତେ ହେବ?
ପ୍ରଶ୍ନ ୨: ଏକ ଛେଦକ ଦୁଇଟି ସମାନ୍ତର ରେଖାକୁ ଛେଦ କଲେ, ଏକାନ୍ତର ଅନ୍ତଃସ୍ଥ କୋଣ (Alternate Interior Angles) କେଉଁ ଇଂରାଜୀ ଅକ୍ଷର ଆକୃତି ସୃଷ୍ଟି କରନ୍ତି?
ପ୍ରଶ୍ନ ୩: ଦୁଇଟି ସମାନ୍ତର ରେଖାକୁ ଛେଦ କରୁଥିବା ଛେଦକର ଏକପାର୍ଶ୍ୱସ୍ଥ ଦୁଇଟି ଅନ୍ତଃକୋଣର ମାପ ଯଥାକ୍ରମେ (୨x)° ଏବଂ (୩x)° ହେଲେ x ର ମାନ କେତେ?
ପ୍ରଶ୍ନ ୪: ଯଦି ରେଖା a || ରେଖା b ଏବଂ ରେଖା b || ରେଖା c ହୁଏ, ତେବେ ରେଖା a ଏବଂ ରେଖା c ମଧ୍ୟରେ ସମ୍ପର୍କ କ’ଣ?
ପ୍ରଶ୍ନ ୫: ଏକ ସରଳରେଖା ଉପରେ ଦୁଇଟି ସଂଲଗ୍ନ କୋଣର ସମଷ୍ଟି ସର୍ବଦା କେତେ ଡିଗ୍ରୀ ହୁଏ?
Section 6

ପରୀକ୍ଷା ହଲ୍ ସତର୍କତା ଓ ୧୫ଟି ତ୍ୱରିତ ରିଭିଜନ୍ ତଥ୍ୟ (Exam Traps & One-Liners)

ପରୀକ୍ଷାରେ ଭୁଲରୁ ବଞ୍ଚିବା ପାଇଁ ଶିକ୍ଷକଙ୍କ ପରାମର୍ଶ ଓ ଦ୍ରୁତ ପୁନରାବୃତ୍ତି ସୂତ୍ର।

ପରୀକ୍ଷାରେ ଏହି ସାଧାରଣ ଭୁଲ କେବେ କରିବେ ନାହିଁ:
• ସମାନ୍ତର ନଥିବା ରେଖାରେ ଅନୁରୂପ କୋଣ ସମାନ ଭାବିବା: ଅନୁରୂପ କୋଣ କେବଳ ସେତିକିବେଳେ ସମାନ ହୁଅନ୍ତି ଯେତେବେଳେ ରେଖାଦ୍ୱୟ ପରସ୍ପର ସମାନ୍ତର ହୋଇଥାନ୍ତି! ସମାନ୍ତର ନଥିଲେ ଅନୁରୂପ କୋଣ ସମାନ ହୁଅନ୍ତି ନାହିଁ।
• ଏକପାର୍ଶ୍ୱସ୍ଥ ଅନ୍ତଃକୋଣକୁ ସମାନ ଲେଖିବା: ଛେଦକର ଏକପାର୍ଶ୍ୱସ୍ଥ ଅନ୍ତଃକୋଣଦ୍ୱୟ ସମାନ ନୁହଁନ୍ତି, ସେମାନଙ୍କର ଯୋଗଫଳ ୧୮୦° (ପରିପୂରକ) ହୋଇଥାଏ।
• ପ୍ରତୀପ କୋଣ ପାଇଁ ସମାନ୍ତରତା ଖୋଜିବା: ପ୍ରତୀପ କୋଣ ସର୍ବଦା ସମାନ, ରେଖାଦ୍ୱୟ ସମାନ୍ତର ହେବା କୌଣସି ଜରୁରୀ ନୁହେଁ।
୧୫ଟି ତ୍ୱରିତ ରିଭିଜନ୍ ଏକ-ପଦୀ ତଥ୍ୟ (15 Rapid Fire Facts):
  1. ଦୁଇଟି ଛେଦୀ ସରଳରେଖାର ଛେଦ ବିନ୍ଦୁ ମାତ୍ର ଗୋଟିଏ ଥାଏ।
  2. ପ୍ରତୀପ କୋଣଦ୍ୱୟ ସର୍ବଦା ପରସ୍ପର ସମାନ।
  3. ରୈଖିକ ଯୁଗ୍ମ କୋଣଦ୍ୱୟର ସମଷ୍ଟି ସର୍ବଦା ୧୮୦°।
  4. ଦୁଇଟି ରେଖା ୯୦° କୋଣରେ ଛେଦ କଲେ ସେମାନଙ୍କୁ ପରସ୍ପର ଲମ୍ବ (⊥) କୁହାଯାଏ।
  5. ସମାନ୍ତର ସରଳରେଖାଦ୍ୱୟ ମଧ୍ୟରେ ଲମ୍ବ ଦୂରତା ସର୍ବଦା ଅପରିବର୍ତ୍ତିତ ରହେ।
  6. ଦୁଇ ବା ତତୋଧିକ ରେଖାକୁ ଭିନ୍ନ ଭିନ୍ନ ବିନ୍ଦୁରେ ଛେଦ କରୁଥିବା ରେଖାକୁ ଛେଦକ (Transversal) କୁହାଯାଏ।
  7. ଛେଦକ ଦୁଇଟି ସମାନ୍ତର ରେଖାକୁ ଛେଦ କଲେ ମୋଟ ୮ଟି କୋଣ ସୃଷ୍ଟି ହୁଏ।
  8. ଅନୁରୂପ କୋଣଗୁଡ଼ିକ F-ଆକୃତି ରେ ରହନ୍ତି ଏବଂ ପରସ୍ପର ସମାନ ହୁଅନ୍ତି।
  9. ଏକାନ୍ତର ଅନ୍ତଃସ୍ଥ କୋଣଗୁଡ଼ିକ Z-ଆକୃତି ରେ ରହନ୍ତି ଏବଂ ପରସ୍ପର ସମାନ ହୁଅନ୍ତି।
  10. ଛେଦକର ଏକପାର୍ଶ୍ୱସ୍ଥ ଅନ୍ତଃକୋଣଦ୍ୱୟ ପରିପୂରକ (ସମଷ୍ଟି = ୧୮୦°) ଅଟନ୍ତି।
  11. ଯଦି ଅନୁରୂପ କୋଣ ସମାନ ହୁଅନ୍ତି, ତେବେ ରେଖାଦ୍ୱୟ ନିଶ୍ଚିତ ଭାବେ ସମାନ୍ତର ହେବେ।
  12. ଯଦି ଏକାନ୍ତର ଅନ୍ତଃସ୍ଥ କୋଣ ସମାନ ହୁଅନ୍ତି, ତେବେ ମଧ୍ୟ ରେଖାଦ୍ୱୟ ସମାନ୍ତର ହେବେ।
  13. ଗୋଟିଏ ରେଖା ସହିତ ସମାନ୍ତର ଥିବା ଦୁଇଟି ରେଖା ପରସ୍ପର ସମାନ୍ତର ହୁଅନ୍ତି।
  14. ସମାନ୍ତର ରେଖା ଉପରେ କେବଳ ଗୋଟିଏ କୋଣର ମାପ ଜଣାପଡ଼ିଲେ ବାକି ୭ଟି କୋଣର ମାପ ବାହାର କରାଯାଇପାରେ।
  15. ବାସ୍ତବ ଜୀବନରେ ରେଳପଥ, ଝରକା ଗ୍ରିଲ୍ ଓ କାଠର ସିଡ଼ି ସମାନ୍ତର ରେଖାର ଉତ୍କୃଷ୍ଟ ଉଦାହରଣ।
