ମାନସିକ ମାନଚିତ୍ର ମୁଖ୍ୟ ଧାରଣା କାର୍ଯ୍ୟକଳାପ ସମାଧାନ NCERT ପ୍ରଶ୍ନୋତ୍ତର ଇଣ୍ଟରାକ୍ଟିଭ୍ କୁଇଜ୍ ପରୀକ୍ଷା ଟିପ୍ସ
NEP ୨୦୨୦ ପାଠ୍ୟକ୍ରମ • ସପ୍ତମ ଶ୍ରେଣୀ ଗଣିତ (ଗଣିତ ପ୍ରକାଶ)

ଅଧ୍ୟାୟ ୩: ବିନ୍ଦୁ ଆରପାରିର ଝଲକ: ଦଶମିକ
(A Peek Beyond the Point)

ଦଶମାଂଶ, ଶତାଂଶ ଓ ସହସ୍ରାଂଶର ଦୁନିଆ, ଦଶମିକ ସ୍ଥାନମାନ ସାରଣୀ, ମାଟ୍ରିକ ଏକକ ରୂପାନ୍ତର, ସଂଖ୍ୟାରେଖାରେ ସ୍ଥାପନ ଓ ସ୍ତମ୍ଭ ଯୋଗ-ବିୟୋଗର ସମ୍ପୂର୍ଣ୍ଣ ମାଷ୍ଟର ନୋଟ୍ସ।

ମୂଳ ପୃଷ୍ଠା » ସପ୍ତମ ଶ୍ରେଣୀ ଗଣିତ » ଅଧ୍ୟାୟ ୩: ବିନ୍ଦୁ ଆରପାରିର ଝଲକ: ଦଶମିକ
Section 1

ଅଧ୍ୟାୟର ରୂପରେଖ ଓ ମାନସିକ ମାନଚିତ୍ର (Visual Mind Map)

ଦଶମିକ ବିନ୍ଦୁ ପାର ହୋଇ ୧୦ ର ଭଗ୍ନାଂଶ ବିଭାଜନକୁ ଗୋଟିଏ ନଜରରେ ବୁଝନ୍ତୁ।

ଶିକ୍ଷକଙ୍କ ପ୍ରବେଶ ବାର୍ତ୍ତା: ଯେତେବେଳେ କୌଣସି ବସ୍ତୁର ଦୈର୍ଘ୍ୟ ୧ ସେଣ୍ଟିମିଟରରୁ କମ୍ ହୁଏ କିମ୍ବା ଟଙ୍କା ୧ ଟଙ୍କାରୁ କମ୍ (ପଇସା) ହୁଏ, ସେତେବେଳେ ପୂର୍ଣ୍ଣସଂଖ୍ୟା ଯଥେଷ୍ଟ ହୁଏ ନାହିଁ! ଆମକୁ ୧ କୁ ୧୦ ଭାଗ (ଦଶମାଂଶ), ୧୦୦ ଭାଗ (ଶତାଂଶ) କିମ୍ବା ୧୦୦୦ ଭାଗ (ସହସ୍ରାଂଶ) ରେ ବାଣ୍ଟିବାକୁ ପଡ଼େ। ଦଶମିକ ବିନ୍ଦୁ (.) ହେଉଛି ସେହି ସୁନ୍ଦର ଦ୍ୱାରବନ୍ଧ, ଯାହାର ବାମ ପାଖରେ ପୂର୍ଣ୍ଣସଂଖ୍ୟା ଓ ଡାହାଣ ପାଖରେ ଭଗ୍ନାଂଶ ରହନ୍ତି!

ଚିତ୍ର ୩.୧: ଦଶମିକ ସଂଖ୍ୟାର ସ୍ଥାନମାନ ଓ ଗାଣିତିକ ରୂପାନ୍ତରଣ ମାନଚିତ୍ର

Section 2

ଗଭୀର ଧାରଣା ଓ ଶିକ୍ଷକଙ୍କ ସରଳ ବିଶ୍ଳେଷଣ (Core Concepts)

ଦଶମାଂଶ, ଶତାଂଶ, ସହସ୍ରାଂଶ ଏବଂ ସ୍ଥାନମାନ ସାରଣୀର ବିସ୍ତୃତ ଅଧ୍ୟୟନ।

୩.୧ କ୍ଷୁଦ୍ର ଏକକର ଆବଶ୍ୟକତା (The Need for Tenths)

ସୋନୁର ମାଆ ଗୋଟିଏ ଖେଳଣାର ସ୍କ୍ରୁ (Screw) ଟାଇଟ୍ କରୁଥିଲେ। ସେ ଲକ୍ଷ୍ୟ କଲେ ଯେ ସ୍କ୍ରୁଟିର ଲମ୍ବ ୨ ସେମି ରୁ ବଡ଼, କିନ୍ତୁ ୩ ସେମି ରୁ ଛୋଟ। ସ୍କେଲ୍ ରେ ଦେଖିବାରୁ ଜଣାପଡ଼ିଲା ଯେ ଏହା ୨ ସେଣ୍ଟିମିଟର ଏବଂ ୪ ମିଲିମିଟର। ଏହାକୁ ଗୋଟିଏ ସଂଖ୍ୟାରେ କିପରି ଲେଖିବା? ୨.୪ ସେଣ୍ଟିମିଟର!

ଚିତ୍ର ୩.୨: ୧ ସମଗ୍ର କୁ ୧୦ ସମାନ ଭାଗରେ ବାଣ୍ଟିଲେ ପ୍ରତ୍ୟେକ ଭାଗ ୧/୧୦ = ୦.୧ (ଦଶମାଂଶ) ଅଟେ।

୩.୨ ଶତାଂଶ ଓ ସହସ୍ରାଂଶ (Hundredths and Thousandths)

ଯେତେବେଳେ ୧ ଦଶମାଂଶ (୦.୧) କୁ ପୁନର୍ବାର ୧୦ ସମାନ ଭାଗ କରାଯାଏ, ପ୍ରତ୍ୟେକ ଭାଗ ହୁଏ ୧/୧୦୦ = ୦.୦୧ (ଶତାଂଶ)। ଯେତେବେଳେ ୧ ଶତାଂଶକୁ ଆହୁରି ୧୦ ଭାଗ କରାଯାଏ, ପ୍ରତ୍ୟେକ ଭାଗ ହୁଏ ୧/୧୦୦୦ = ୦.୦୦୧ (ସହସ୍ରାଂଶ)।

ଶତକ (୧୦୦) ଦଶକ (୧୦) ଏକକ (୧) ଦଶମିକ ବିନ୍ଦୁ (.) ଦଶମାଂଶ (୧/୧୦) ଶତାଂଶ (୧/୧୦୦) ସହସ୍ରାଂଶ (୧/୧୦୦୦)
— ୨ ୫ . ୩ ୭ —
୧ ୦ ୪ . ୦ ୨ ୫

୩.୩ ମାଟ୍ରିକ ଏକକ ରୂପାନ୍ତର (Metric Unit Conversions)

ସମସ୍ତ ମାଟ୍ରିକ ଏକକ ୧୦, ୧୦୦ କିମ୍ବା ୧୦୦୦ ଦ୍ୱାରା ପରିଚାଳିତ:

• ୧ ସେମି = ୧୦ ମିମି ⇒ ୧ ମିମି = ୧/୧୦ ସେମି = ୦.୧ ସେମି
• ୧ ମିଟର = ୧୦୦ ସେମି ⇒ ୧ ସେମି = ୧/୧୦୦ ମି = ୦.୦୧ ମି
• ୧ କିଲୋମିଟର = ୧,୦୦୦ ମିଟର ⇒ ୧ ମି = ୧/୧୦୦୦ କିମି = ୦.୦୦୧ କିମି
• ୧ କିଲୋଗ୍ରାମ = ୧,୦୦୦ ଗ୍ରାମ ⇒ ୧ ଗ୍ରାମ = ୧/୧୦୦୦ କିଗ୍ରା = ୦.୦୦୧ କିଗ୍ରା
• ୧ ଟଙ୍କା = ୧୦୦ ପଇସା ⇒ ୧ ପଇସା = ₹ ୧/୧୦୦ = ₹ ୦.୦୧

୩.୪ ଦଶମିକ ତୁଳନାର ଗୋପନୀୟ ସୂତ୍ର (Comparing Decimals)

ଛାତ୍ରଛାତ୍ରୀଙ୍କ ସାଧାରଣ ଭ୍ରାନ୍ତି: "୦.୪୬ ହେଉଛି ୦.୫ ଠାରୁ ବଡ଼, କାରଣ ୪୬ ସଂଖ୍ୟାଟି ୫ ଠାରୁ ବଡ଼!"
ଶିକ୍ଷକଙ୍କ ସଂଶୋଧନ: ଦଶମିକକୁ କେବେ ପୂର୍ଣ୍ଣସଂଖ୍ୟା ପରି ତୁଳନା କରନ୍ତୁ ନାହିଁ! ଡାହାଣ ପାଖରେ ଶୂନ (୦) ଯୋଡ଼ି ଉଭୟଙ୍କ ଦଶମିକ ସ୍ଥାନ ସମାନ କରନ୍ତୁ:
• ୦.୫ = ୦.୫୦ (୫୦ ଶତାଂଶ)
• ୦.୪୬ = ୦.୪୬ (୪୬ ଶତାଂଶ)
ଯେହେତୁ ୫୦ ଶତାଂଶ > ୪୬ ଶତାଂଶ, ତେଣୁ ୦.୫ > ୦.୪୬!
Section 3

ପାଠ୍ୟପୁସ୍ତକ ଅନ୍ତର୍ଗତ କାର୍ଯ୍ୟକଳାପର ସମ୍ପୂର୍ଣ୍ଣ ସମାଧାନ (In-Text Activities)

ସଂଖ୍ୟାରେଖାରେ ବିନ୍ଦୁ ଚିହ୍ନଟ ଓ ସ୍ତମ୍ଭ ବିୟୋଗର ପଦକ୍ଷେପ-ୱାରୀ ସମାଧାନ।

କାର୍ଯ୍ୟକଳାପ ୧: ସଂଖ୍ୟାରେଖାରେ ଅକ୍ଷର ଚିହ୍ନଟ (ପୃଷ୍ଠା ୩୪)

୬.୪, ୬.୫ ଏବଂ ୬.୬ ମଧ୍ୟରେ ୧୦ଟି ଲେଖାଏଁ ସମାନ ଭାଗ ଥିବା ସଂଖ୍ୟାରେଖାରେ a, b, c ର ମାନ ନିର୍ଣ୍ଣୟ କରନ୍ତୁ:

ଅକ୍ଷର a: ୬.୪ ପରେ ୩ୟ ଗାରରେ ଅଛି ⇒ ୬.୪ + ୦.୦୩ = ୬.୪୩।
ଅକ୍ଷର b: ୬.୪ ପରେ ୭ମ ଗାରରେ ଅଛି ⇒ ୬.୪ + ୦.୦୭ = ୬.୪୭।
ଅକ୍ଷର c: ୬.୫ ପରେ ୪ର୍ଥ ଗାରରେ ଅଛି ⇒ ୬.୫ + ୦.୦୪ = ୬.୫୪।
✓ ଉତ୍ତର: a = ୬.୪୩, b = ୬.୪୭, c = ୬.୫୪।

କାର୍ଯ୍ୟକଳାପ ୨: ସ୍ଥାନମାନ ବିୟୋଗ (ପୃଷ୍ଠା ୩୦)

ବିୟୋଗ କର: ୮୪.୬୯୧ − ୭୭.୩୪୫

ସହସ୍ରାଂଶ: ୧ ରୁ ୫ ବିୟୋଗ ଯିବ ନାହିଁ ⇒ ୧ ଶତାଂଶ ହାର ନେଲେ ୧୧ − ୫ = ୬ ସହସ୍ରାଂଶ।

Section 4

୧୦୦% ସମ୍ପୂର୍ଣ୍ଣ NCERT ଅଭ୍ୟାସ ପ୍ରଶ୍ନାବଳୀ ସମାଧାନ (Figure it Out)

ପାଠ୍ୟପୁସ୍ତକ ଅନୁଶୀଳନୀର ପ୍ରତ୍ୟେକ ପ୍ରଶ୍ନର ପୂର୍ଣ୍ଣ ସମାଧାନ।

ପ୍ରଶ୍ନ ୧: ଭଗ୍ନାଂଶକୁ ଦଶମିକରେ ରୂପାନ୍ତର କର (ପୃଷ୍ଠା ୫୨)

(ଗ) ୧୨/୧୦ ⇒ ୧୨ ଦଶମାଂଶ = ୧ ସମଗ୍ର ଓ ୨ ଦଶମାଂଶ = ୧.୨।

ପ୍ରଶ୍ନସମାଧାନ ପ୍ରକ୍ରିୟା (ବିନ୍ଦୁ ସମରେଖନ ଓ ଶୂନ ଯୋଗ)ଚୂଡ଼ାନ୍ତ ମାନ
