Section 02

Deep-Dive Core Concepts & Teacher Explanations

1. The Secrets of Consecutive Numbers

Let three consecutive natural numbers be n, n + 1, and n + 2.

Sum of 3 Consecutive Numbers:
Sum = n + (n + 1) + (n + 2) = 3n + 3 = 3(n + 1).
Teacher's Insight: The sum of any 3 consecutive numbers is ALWAYS a multiple of 3, and is exactly 3 times the middle number!
Check: 14 + 15 + 16 = 45 = 3 × 15.
What About 4 Consecutive Numbers?
Sum = n + (n + 1) + (n + 2) + (n + 3) = 4n + 6 = 4(n + 1) + 2.
Surprise: The sum of 4 consecutive numbers is NEVER a multiple of 4! It always leaves a remainder of 2 when divided by 4!

2. Proving Divisibility Rules with Algebra

Any 3-digit number with digits a (hundreds), b (tens), and c (ones) is written in expanded place-value notation as:

N = 100a + 10b + c

A. Divisibility by 10 and 5

100a and 10b are both divisible by 10 and 5. Therefore:
• N is divisible by 10 if and only if the last digit c = 0.
• N is divisible by 5 if and only if the last digit c is 0 or 5.

B. Divisibility by 3 and 9 (The Magic Decomposition)

Notice how we can cleverly rewrite 100a + 10b + c:

N = 100a + 10b + c
N = (99a + a) + (9b + b) + c
N = (99a + 9b) + (a + b + c)
N = 9(11a + b) + (a + b + c)
The Proof Revealed: The first part, 9(11a + b), is ALWAYS divisible by 9 (and therefore by 3).
Thus, the whole number N is divisible by 9 (or 3) if and only if the remainder (a + b + c) is divisible by 9 (or 3)!
That is why adding the digits works!

C. Divisibility by 11 (Alternating Sum)

Notice: 100 = 99 + 1, and 10 = 11 - 1.
N = 100a + 10b + c = (99a + 11b) + (a - b + c).
Since 99a + 11b is divisible by 11, N is divisible by 11 if and only if (a + c) - b is 0 or a multiple of 11.

3. Cryptarithms: Cracking Letter Puzzles

Rules of Cryptarithms:
1. Each letter represents a distinct digit from 0 to 9.
2. The first (leading) digit of any number CANNOT be 0.
3. Carry-overs follow standard column addition or multiplication rules.
Section 03

In-Text Activities & Classroom Explorations (Fully Solved)

Activity 1 (Page 9): If a number is divisible by 7, is it also divisible by any multiple of 7?

Answer: No! This is a common misconception.

Example: 14 is divisible by 7. But 14 is NOT divisible by 21, 28, or 35 (which are multiples of 7).

The reverse statement is true: If a number is divisible by a multiple of 7 (say 28), then it is always divisible by 7.

Activity 2 (Page 19): How do we check divisibility by 24 without doing long division?

Co-Prime Factor Rule: To test divisibility by a composite number like 24, find two factors of 24 that are co-prime (gcd = 1).

Factors of 24: 3 × 8 = 24, and gcd(3, 8) = 1.

Rule: A number is divisible by 24 if and only if it is divisible by BOTH 3 and 8.

  • Divisible by 3: Sum of digits is divisible by 3.
  • Divisible by 8: Last 3 digits form a number divisible by 8.
Activity 3 (Page 21): Solve the cryptarithm: 3A + 25 = B2. Find the digits A and B.

Step 1 (Units Column): A + 5 ends in 2.

Since A is a single digit: A + 5 = 12 ⇒ A = 7 (with a carry of 1 to the tens column).

Step 2 (Tens Column): 1 (carry) + 3 + 2 = B ⇒ B = 6.

Verification: 37 + 25 = 62. Both digits are unique!

Section 04

Complete End-of-Chapter 'Figure it Out' Exercises (Solved Step-by-Step)

Exercise 1: If 21y5 is a multiple of 9, where y is a digit, what are the possible values of y?
Rule: A number is divisible by 9 if the sum of its digits is a multiple of 9.
Sum of digits: 2 + 1 + y + 5 = 8 + y.
Possible Multiples: 8 + y must equal 9 or 18 (since y is a single digit between 0 and 9).
Solving: 8 + y = 9 ⇒ y = 1. (If 8 + y = 18 ⇒ y = 10, which is not a single digit).
Result: The only possible value of y is 1. (Number is 2115).
Exercise 2: Find the values of letters A and B in: AB × 3 = CAB.
Units column: B × 3 ends in B. What digits satisfy B × 3 ending in B?
• 0 × 3 = 0 (B = 0)
• 5 × 3 = 15 (B = 5)
Case 1 (B = 0): A0 × 3 = CA0 ⇒ A × 3 ends in A. If A = 5: 50 × 3 = 150 (Here C=1, A=5, B=0). All unique!
Case 2 (B = 5): A5 × 3 = CA5. Carry is 1. 3A + 1 ends in A. 2A ends in 9 (no integer solution).
Result: A = 5, B = 0, C = 1 (50 × 3 = 150).
Exercise 3: Prove that the product of any three consecutive integers is always divisible by 6.
Let integers be: n, n + 1, n + 2.
Divisibility by 2: Among any two consecutive integers, at least one must be even. Hence, the product contains a factor of 2.
Divisibility by 3: Among any three consecutive integers, exactly one must be a multiple of 3. Hence, the product contains a factor of 3.
Combination: Since gcd(2, 3) = 1, the product is divisible by 2 × 3 = 6.
Result: Proved for all integers.

1. If a 4-digit number 31z5 is divisible by 9, what is the value of digit z?

Teacher Explanation
Correct Answer: (b) 9 (or 0 if 3105, 3+1+0+5=9).
Sum of digits: 3 + 1 + z + 5 = 9 + z. For 9+z to be divisible by 9, z can be 0 or 9!

2. What is the sum of any three consecutive natural numbers always divisible by?

Teacher Explanation
Correct Answer: (c) 3.
n + (n+1) + (n+2) = 3n + 3 = 3(n+1), which has 3 as a common factor.

3. To test if a number is divisible by 12, which two co-prime tests should you use?

Teacher Explanation
Correct Answer: (a) 3 and 4.
2 and 6 are NOT co-prime (gcd(2,6) = 2). 3 and 4 have gcd = 1, so both conditions guarantee divisibility by 12.

4. In the cryptarithm 4A + 98 = 1CB, what is the value of B if A = 7?

Teacher Explanation
Correct Answer: (d) 5.
47 + 98 = 145. Comparing with 1CB: C = 4, B = 5.

5. Which of the following numbers is divisible by 11?

Teacher Explanation
Correct Answer: (b) 1331.
Odd places: 1 + 3 = 4. Even places: 3 + 1 = 4. Difference = 4 - 4 = 0. Hence 1331 is divisible by 11.

Quick Revision Notes & Common Pitfalls

Pitfall: Assuming that because 6 = 2 × 3, divisibility by 8 means checking 2 and 4!
A number can be divisible by 2 and 4 (like 12) without being divisible by 8! You can ONLY split tests into factors that are CO-PRIME!
