13.1 Linear Equations in Two Variables: Genesis & Meaning

In everyday life, quantities rarely exist in isolation; they are tied together by practical constraints such as money, time, distance, and weight. Consider the opening scenario of Chapter 13:

The Fruit Cart Dilemma: Radha's Purchase

Radha stops at a local fruit cart where mangoes are priced at ₹60 per kg and bananas cost ₹50 per kg. She purchases a certain quantity of mangoes and bananas, and the vendor bills her a total of ₹280.

Because the individual weights are unknown, we assign two mathematical variables:

  • Let x = number of kilograms of mangoes purchased
  • Let y = number of kilograms of bananas purchased

The total cost of mangoes is ₹60 × x = 60x and the total cost of bananas is ₹50 × y = 50y. Combining these gives the linear equation:

60x + 50y = 280

Dimensional Consistency Check: The Left-Hand Side (LHS) represents the total money spent in rupees, and the Right-Hand Side (RHS) represents the exact bill amount in rupees. The equals sign (=) establishes a strict physical and financial balance.

The algebraic expression 60x + 50y = 280 is called a linear equation in two variables. It is "linear" because the exponent (power) of each variable is exactly 1, and there are no cross-product terms like xy, x², or √y.

13.1.1 Standard Form of a Linear Equation in Two Variables

Formal Definition: Standard Form

Any equation that can be expressed in the form:

ax + by + c = 0

where a, b, and c are real numbers (a, b, c ∈ ℝ), and a and b are not both zero (a² + b² ≠ 0), is called a linear equation in two variables in standard form.

  • a is the coefficient of x
  • b is the coefficient of y
  • c is the constant term

Crucial Structural Observations on Standard Form

  1. Rational Coefficients and Clearing Denominators: The coefficients a, b and constant c need not be integers; they can be fractions. For example, consider:
    ¼ x + ⅗ y - ½ = 0
    While this is already in standard form with a = ¼, b = ⅗, and c = -½, in algebra we multiply the entire equation by the Least Common Multiple (LCM) of the denominators (LCM(4, 5, 2) = 20):
    20 × (¼ x + ⅗ y - ½) = 20 × 0 ⇒ 5x + 12y - 10 = 0
    Both equations represent the exact same geometric line and have identical solution sets!
  2. Single-Variable Linear Equations as Degenerate Two-Variable Cases: An equation of the form ax + c = 0 (where b = 0) or by + c = 0 (where a = 0) can always be written in two variables by supplying a coefficient of 0 for the missing variable:
    7 + 4x = 0 ⇔ 4x + 0y + 7 = 0   (a = 4, b = 0, c = 7)
    3y = 5 ⇔ 0x + 3y - 5 = 0   (a = 0, b = 3, c = -5)
  3. Sign Symmetry: If we multiply ax + by + c = 0 throughout by -1, we obtain -ax - by - c = 0. Both forms are equally valid standard forms representing the identical mathematical line.

13.2 Solution of a Linear Equation in Two Variables

13.2.1 Algebraic Meaning of a Solution

In a single-variable linear equation such as 2x + 6 = 0, there is only one unique solution: x = -3. But what constitutes a solution when two variables are involved?

Definition: Solution as an Ordered Pair

A solution of a linear equation in two variables ax + by + c = 0 is an ordered pair of real numbers (u, v) such that when x = u and y = v are substituted into the equation, the Left-Hand Side evaluates exactly to the Right-Hand Side:

a(u) + b(v) + c = 0

Order Matters: We write solutions as (x, y). The first entry is always the value of the horizontal variable x, and the second entry is the vertical variable y. Hence, (2, 3) ≠ (3, 2)!

Consider the equation 3x + 2y = 12:

  • If we test (2, 3): 3(2) + 2(3) = 6 + 6 = 12. Since 12 = 12, (2, 3) is a solution!
  • If we test (4, 0): 3(4) + 2(0) = 12 + 0 = 12. Thus, (4, 0) is a solution!
  • If we test (1, 3): 3(1) + 2(3) = 3 + 6 = 9 ≠ 12. Thus, (1, 3) is NOT a solution!
The Infinity Engine: Generating Endless Solutions

How many solutions does a linear equation in two variables have? Infinitely many!

To see why, express one variable explicitly in terms of the other:

3x + 2y = 12 ⇒ 2y = 12 - 3x ⇒ y = 6 - 1.5x

Because the real numbers ℝ are infinite and continuous, you can pick any real value whatsoever for x (say x = u), and the formula immediately computes a unique corresponding value y = 6 - 1.5u. Since there are infinitely many choices for x, there are infinitely many ordered pairs (u, 6 - 1.5u) that satisfy the equation.

13.2.2 Geometric Visualisation: From Algebraic Pairs to a Continuous Line

What happens when we plot all these infinite ordered pairs (x, y) on a Cartesian coordinate plane? They do not scatter randomly across the plane. Instead, they align in a perfect, unbroken straight line!

The Intercept Method: The Fastest Way to Graph Any Line

To graph any linear equation ax + by = c (with c ≠ 0), you only need to determine two strategic anchor points where the line meets the coordinate axes:

  1. Find the y-intercept: Substitute x = 0 into the equation and solve for y. This produces point (0, c/b).
  2. Find the x-intercept: Substitute y = 0 into the equation and solve for x. This produces point (c/a, 0).
  3. Connect with a Ruler: Plot both points and draw the straight line through them, placing arrows at both ends to indicate it continues infinitely.

Lines Through the Origin: When Constant c = 0

In the textbook discussion (Section 13.2, Think and Reflect), Ranju, Meena, Farhan, and Toshi explore what occurs when c = 0 in ax + by + c = 0:

The Zero-Constant Theorem

Whenever the constant term c = 0, the equation simplifies to ax + by = 0.

If we test the coordinates of the origin (0, 0):

a(0) + b(0) = 0 + 0 = 0

The equation is identically satisfied! Therefore, every straight line of the form ax + by = 0 passes directly through the origin (0, 0), regardless of the numerical values of a and b.

  • When a = 1, b = 0, c = 0: x = 0 is the equation of the y-axis (which passes through the origin).
  • When a = 0, b = 1, c = 0: y = 0 is the equation of the x-axis (which passes through the origin).

13.3 Slope-Intercept Form of a Linear Equation: Gradient Physics

13.3.1 Understanding Slope (Gradient)

Have you ever ridden a bicycle up an incline? On a flat, horizontal road, you pedal smoothly with minimal effort. But when the road begins to tilt upwards into a hill, pedaling becomes significantly harder. The greater the incline, the more muscular effort you must expend. In physics and mathematics, this measure of "steepness" is formalized as the slope or gradient of a line.

Figure 13.2: The Geometric Anatomy of Slope. The slope is the exact ratio of the vertical step (Rise = y₂ - y₁) to the horizontal step (Run = x₂ - x₁).
Mathematical Definition of Slope

For any two distinct points A(x₁, y₁) and B(x₂, y₂) on a non-vertical line:

Slope (m) = Rise / Run = (y₂ - y₁) / (x₂ - x₁) = (y₁ - y₂) / (x₁ - x₂)
  • Run (x₂ - x₁): The horizontal distance moved from left to right. Moving right is positive (+); moving left is negative (-).
  • Rise (y₂ - y₁): The vertical distance moved up or down. Moving up is positive (+); moving down is negative (-).
  • Order Invariance: As proved in Example 6, swapping the order of points leaves the slope unchanged because (-Rise) / (-Run) = (+Rise) / (+Run) = m.

13.3.2 The Slope-Intercept Equation: y = mx + d

Every standard linear equation ax + by + c = 0 (where b ≠ 0) can be solved directly for y:

by = -ax - c ⇒ y = (-a/b)x + (-c/b)

If we define m = -a/b and d = -c/b, the equation takes the famous slope-intercept form:

y = mx + d
Why does 'm' rigorously represent the slope? A 3-Line Proof

Let A(x₁, y₁) and B(x₂, y₂) be any two points on the line y = mx + d. Because both points satisfy the equation:

y₁ = mx₁ + d     and     y₂ = mx₂ + d

Subtracting y₁ from y₂:

Rise = y₂ - y₁ = (mx₂ + d) - (mx₁ + d) = mx₂ - mx₁ = m(x₂ - x₁)

Dividing by the horizontal run (x₂ - x₁):

Rise / Run = m(x₂ - x₁) / (x₂ - x₁) = m

Q.E.D.: The coefficient m is identically equal to the geometric slope for every pair of points on the line, completely independent of which points are chosen!

13.4 & 13.5 Systems of Linear Equations in Two Variables

A single linear equation in two variables has infinitely many solutions. But when real-world problems impose two simultaneous constraints on the same variables, we obtain a pair of linear equations in two variables:

a₁x + b₁y + c₁ = 0     and     a₂x + b₂y + c₂ = 0

A simultaneous solution is a specific ordered pair (x₀, y₀) that satisfies both equations at the same time.

The Two Classic Algebraic Solvers

Method 1: The Substitution Method

Core Philosophy: Isolate one variable in terms of the other from one equation, and plug it directly into the second equation, reducing it to a single-variable equation.

  1. Pick the equation with the simplest coefficient (ideally 1 or -1). Express x in terms of y: x = g(y).
  2. Substitute this expression for x in the other equation.
  3. Solve the resulting linear equation for y.
  4. Substitute the value of y back into x = g(y) to find x.
  5. Check by substituting both into the original equations.

Method 2: The Elimination Method

Core Philosophy: Equalize the absolute values of the coefficients of one variable across both equations using scalar multipliers, then add or subtract to eliminate that variable.

  1. Multiply Equation (1) by b₂ and Equation (2) by b₁ (or by their LCM multipliers).
  2. If the coefficients have the same sign, subtract the equations. If opposite signs, add them.
  3. The targeted variable cancels completely (0y), leaving a clean equation in x.
  4. Solve for x, then back-substitute to find y.
Mahāvīrāchārya's Symmetric Interchange Technique (c. 850 CE)

When equations have interchanged coefficients of the form:

ax + by = c     and     bx + ay = d

Do NOT multiply by large numbers! Instead, use the ancient Indian symmetric shortcut from the Gaṇita Sāra Saṅgraha:

  • Step 1 (Add Equations): (a + b)x + (a + b)y = c + d ⇒ x + y = (c + d) / (a + b)
  • Step 2 (Subtract Equations): (a - b)x - (a - b)y = c - d ⇒ x - y = (c - d) / (a - b)
  • Step 3 (Solve Simple System): Adding and subtracting these two trivial equations yields x and y in seconds!

A Pinch of History: The Global Roots of Elimination

Solving systems of simultaneous linear equations is over four thousand years old:

  • Babylonian Clay Tablets (c. 2000 BCE): Ancient Mesopotamian scribes formulated and solved simultaneous problems involving fields, storage, and shared grain.
  • Ancient China (Nine Chapters on the Mathematical Art, c. 1st Century CE): Chapter 8, titled Fangcheng, lays out an exact matrix method using columns of counting rods on a board. By performing column operations to eliminate variables, Chinese mathematicians solved simultaneous systems eighteen centuries before Carl Friedrich Gauss popularized "Gaussian elimination" in Europe!
  • Classical Indian Masters (Āryabhaṭa 499 CE & Brahmagupta 628 CE): Āryabhaṭa developed the famous Kuṭṭaka ("Pulverizer") algorithm to solve indeterminate linear equations. Brahmagupta in the Brāhmasphuṭasiddhānta formulated systematic reduction rules for equations with several unknown quantities (Yāvattāvat, Kālaka, Nīlaka) using negative and positive signs.

Think & Reflect 1 (Page 4): Are (1, 9/2), (0, 6), (4, 1) and (1/2, 21/4) solutions of 3x + 2y = 12? How many solutions exist?
Step 1: Given & Identification

Given linear equation: 3x + 2y = 12. We are to test four candidate ordered pairs: (1, 9/2), (0, 6), (4, 1), and (1/2, 21/4), and evaluate the total cardinality of solutions.

Step 2: Formula & Criteria

An ordered pair (x, y) is a solution if and only if LHS = 3x + 2y evaluates to RHS = 12.

Step 3: Algebraic Evaluation
  • For (1, 9/2): 3(1) + 2(9/2) = 3 + 9 = 12 = RHS. ⇒ Valid Solution!
  • For (0, 6): 3(0) + 2(6) = 0 + 12 = 12 = RHS. ⇒ Valid Solution! (y-intercept)
  • For (4, 1): 3(4) + 2(1) = 12 + 2 = 14 ≠ 12. ⇒ NOT a Solution!
  • For (1/2, 21/4): 3(1/2) + 2(21/4) = 3/2 + 21/2 = 24/2 = 12 = RHS. ⇒ Valid Solution!
Step 4: Verification & Generalization

• Unique solution ⇔ a₁/a₂ ≠ b₁/b₂.
• Infinitely many solutions ⇔ a₁/a₂ = b₁/b₂ = c₁/c₂.

1. Cross-Multiplication Method: Using determinants: x / (b₁c₂ - b₂c₁) = y / (c₁a₂ - c₂a₁) = 1 / (a₁b₂ - a₂b₁).
2. Matrix Inversion: AX = B ⇒ X = A⁻¹B.
3. Graphical Intersection: Reading coordinates directly from grid paper.

Part 3: Proof that Two Lines of Equal Slope are Parallel

Consider two lines with equal slope m and distinct y-intercepts: L₁: y = mx + d₁ and L₂: y = mx + d₂ with d₁ ≠ d₂.

Proof by contradiction: Assume they intersect at some point (x₀, y₀). Then:

y₀ = mx₀ + d₁     and     y₀ = mx₀ + d₂

Equating both expressions for y₀:

mx₀ + d₁ = mx₀ + d₂ ⇒ d₁ = d₂

This directly contradicts the given fact that d₁ ≠ d₂! Hence, no such intersection point (x₀, y₀) can exist. The lines never meet, which means they are strictly parallel. Q.E.D.

Step 5: Concluding Takeaway

Equal slope guarantees identical orientation. When intercepts differ, the lines are separated by a constant vertical distance |d₁ - d₂| and can never intersect.

After 20 years: Father is 40 + 20 = 60. Children's sum is 40 + 80 = 120.
Is 120 = 2 × 60? Yes, exactly twice! Condition holds perfectly.

Step 5: Concluding Answer

The present age of the father is 40 years.

Exam Hall Trap Alerts & 15 High-Yield Revision Points

5 Common Student Blunders & Exam Traps

Trap 1: The Transposition Sign Blunder in Standard Form

Student Blunder: When rewriting 5x = 3y - 7 in standard form, writing 5x + 3y + 7 = 0.

Why It Fails: Moving a positive term across the equals sign changes its sign to negative! 3y becomes -3y, and -7 becomes +7.

Correct Approach: 5x - 3y + 7 = 0, where a = 5, b = -3, c = 7.

Trap 2: Inverting Rise and Run in Slope Calculation

Student Blunder: Calculating slope as m = (x₂ - x₁) / (y₂ - y₁) (Run / Rise).

Why It Fails: Slope is strictly vertical change over horizontal change: m = Δy / Δx. Inverting the fraction yields the reciprocal gradient.

Pro-Memory Tip: Remember: You must RISE up out of bed before you can RUN! Rise is on top!

Trap 3: Confusing Zero Slope (Horizontal) with Undefined Slope (Vertical)

Student Blunder: Stating that vertical line x = 3 has slope 0, and horizontal line y = 5 has undefined slope.

Correction: Horizontal line has Rise = 0, so 0 / Run = 0 (Slope = 0). Vertical line has Run = 0, so Rise / 0 is undefined!

Trap 4: Forgetting Constant Term Placement in Ratio Comparisons

Student Blunder: Comparing c₁/c₂ when one equation is written as ax + by = c and the other is ax + by + c = 0.

Correction: Always arrange BOTH equations in the exact same format before computing ratios!

Trap 5: Multi-Child Age Addition Fallacy

Student Blunder: In *End Exercise 16, adding 20 years to the sum of 4 children's ages instead of 4 × 20 = 80 years.

Correction: If n children age by t years, their combined age increases by n × t years!

15 High-Yield Rapid Revision Points

  1. Standard Form: Any linear equation in two variables can be expressed as ax + by + c = 0, with real coefficients and a² + b² ≠ 0.
  2. Continuous Solution Space: A single linear equation in two variables has an infinite number of solutions, each represented by an ordered pair (x, y).
  3. Geometric Locus: The graph of every linear equation in two variables is a continuous straight line in the Cartesian plane.
  4. Origin Invariant: A straight line passes through the origin (0, 0) if and only if its constant term c = 0 (ax + by = 0).
  5. Axes Equations: The equation of the x-axis is y = 0; the equation of the y-axis is x = 0.
  6. Slope / Gradient: The slope m is defined as Rise / Run = (y₂ - y₁) / (x₂ - x₁) and remains strictly constant along the entire line.
  7. Slope-Intercept Form: y = mx + d, where m = -a/b is the slope and d = -c/b is the y-intercept (0, d).
  8. Slope Orientations: m > 0 rises left-to-right; m < 0 falls left-to-right; m = 0 is horizontal; vertical lines have an undefined slope.
  9. Simultaneous System: A pair of linear equations has solutions that simultaneously satisfy both mathematical conditions.
  10. Substitution Method: Express one variable in terms of the other from one equation and substitute into the second.
  11. Elimination Method: Multiply equations by constants to equalize the coefficients of one variable, then add or subtract to eliminate it.
  12. Mahāvīrāchārya's Symmetric Rule: For ax + by = c and bx + ay = d, add and subtract equations to obtain simplified sums and differences.
  13. Unique Solution Test: If a₁/a₂ ≠ b₁/b₂, lines intersect at exactly one point (Consistent & Independent).
  14. Infinite Solutions Test: If a₁/a₂ = b₁/b₂ = c₁/c₂, lines coincide (Consistent & Dependent).
  15. No Solution Test: If a₁/a₂ = b₁/b₂ ≠ c₁/c₂, lines are parallel and never meet (Inconsistent).
